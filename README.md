# ISRP HR Handbook

Standalone Mintlify project: extract this ZIP, place its contents at your docs repository root with docs.json, and connect that repository to Mintlify. Each of the three archives is independent; do not combine their docs.json files. Use separate Mintlify sites for independent deployment.

Follow current Mintlify CLI setup instructions and use `mint dev` to preview. Runtime build has not been tested here. Configure real audience access before publishing.

Expandable sections use native Accordion components. Temporary text-only logos are included, not the inaccessible supplied official logo. Replace them before launch. Original GitBook visuals could not be inspected; this is an adapted interactive handbook, not a verified pixel-perfect clone.

See PRE-LAUNCH-CHECKLIST.md for pending policies and integrations.
